# Post-Launch Monitoring Checklist

## Day 1

Check:

- Website form.
- Booking flow.
- Email confirmation.
- Admin notification.
- SMS if included.
- CRM record.
- Dashboard visibility.
- Client feedback.

Day 1 done criteria: lead capture, booking, notification, and dashboard visibility are verified or an urgent/high fix is opened with owner and proof path.

## Day 2

Check:

- Follow-up automations.
- Missed call flow if included.
- Lead source tracking.
- Errors/warnings.
- Client questions.

Day 2 done criteria: follow-up paths and client questions are reviewed, with open issues prioritized.

## Day 3

Check:

- Nurture sequence.
- Booking handoff.
- Daily digest.
- CRM status updates.
- Support issues.

Day 3 done criteria: scheduled and delayed automations are verified, or blocked with a specific provider/access/client decision.

## Day 7

Check:

- Complete automation health.
- Lead routing accuracy.
- Client satisfaction.
- Open fix log.
- Monthly support transition.

Day 7 done criteria: week-one monitoring is complete, unresolved items have priority/owner, and the client is transitioned to monthly support.
