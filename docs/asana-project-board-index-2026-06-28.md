## Operating Rule

The Master Launch OS board remains the command center. Specialized boards can hold detailed work, but Asana completion should only sync back to launch status when the proof standard is met:

- Built = code/doc/config exists
- Configured = settings and IDs are present
- Tested = safe test executed
- Proven = production-safe proof record exists

Do not confuse these four statuses.
