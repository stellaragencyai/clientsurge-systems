# Industry Routing Plan

## Goal
Keep the main website focused while making industry landing pages useful entry points instead of second homepages.

## Primary Rule
Every industry page should do one of two jobs:
1. send high-intent visitors straight to the main CTA
2. send exploratory visitors back to the main website for fuller trust-building

## Routing Model

### Main Homepage `/`
Use for:
1. brand traffic
2. referrals
3. broad organic traffic
4. visitors comparing providers

Primary CTA:
`Book Your Free Demo`

Secondary path:
`See Industry-Specific Examples`

### Flagship Industry Pages
Use for:
1. ad traffic
2. niche outbound traffic
3. high-intent search traffic

Current flagship:
1. `/med-spa`

Primary CTA:
`Book Your Free Demo`

Secondary CTA:
`See How ClientSurge Works`

### Future Industry Pages
Suggested structure:
1. `/industries/hvac`
2. `/industries/dental`
3. `/industries/chiropractic`
4. `/industries/legal`
5. `/industries/home-services`

## Industry Page Structure
1. Niche-specific hero
2. Top 3 operational problems for that niche
3. How the automation system fixes those problems
4. One proof block or mini case study
5. One primary CTA
6. One secondary link back to the main website

## CTA Rules
1. Do not add multiple competing primary buttons on an industry page.
2. Keep CTA language consistent with the homepage.
3. If proof is weak for a niche, send more traffic back to `/`.

## Recommended Next Implementation Order
1. Keep `/med-spa` as the strongest vertical page.
2. Add an `/industries` overview page only after two or more niche pages are production-ready.
3. Build future vertical pages from one shared structure, not from homepage copies.
